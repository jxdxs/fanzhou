# 泛舟 (Fanzhou) 设置页面「配置备份与同步」优化与演进建议

本文档针对泛舟（Fanzhou）现有的配置备份与同步模块（涉及网盘 Token、Jellyfin 凭证、播放历史/断点、偏好设置、WebDAV 同步及 AES-256 加密体系），从**界面视觉层级**、**多用户/多设备协同隔离**、**备份细粒度控制**、**数据容灾与快照**以及 **Android TV 大屏交互适配**五个维度，提出系统性优化与演进方案。

---

## 一、 现状分析与痛点识别

泛舟目前在 `v2.3.38` ~ `v2.3.41` 已实现了核心的备份与同步能力：
1. **身份标识**：支持 `profileName`（如“个人”、“客厅电视”、“张三”）；
2. **本地文件备份**：支持导出与导入 JSON 文件，支持可选的 `AES-256-GCM` + `PBKDF2WithHmacSHA256` 密码加密；
3. **WebDAV 云端同步**：支持 WebDAV URL、账号密码、备份目录及 WebDAV 加密密码；支持应用启动时拉取更新与改动后 15 秒防抖自动上传。

### 存在的主要痛点与交互短板：
1. **大表单信息堆叠，视觉层次混乱**：
   - 现版本将 6 个 `OutlinedTextField`（档案名、WebDAV URL、用户名、密码、目录、加密密码）、两排功能按钮、Switch 开关和说明文字塞在单个折叠卡片内。
   - 手机和电视大屏上纵向滚动过长，缺乏明确的场景分区。
2. **多用户与多设备共用 WebDAV 存在文件覆盖隐患**：
   - 云端文件名固定为 `fanzhou-config.json`。
   - 若家庭多成员或同一用户的多个设备（手机、平板、电视盒子）共用同一个 WebDAV 目录并开启自动同步，会直接互相覆盖彼此的配置与播放记录。
3. **备份缺乏内容分类（全量打包无法按需脱敏）**：
   - 目前全量同步 `fanzhou` 与 `positions` 两个 SharedPreferences。
   - 场景 A：用户只想把配置好的影视源/网盘目录分享给长辈或朋友，但**绝不希望泄露自己的播放历史和私人网盘主账号凭据**；
   - 场景 B：电视端需要保持独立的大缓存与固定解码器偏好，不希望被手机端的偏好覆盖打乱。
4. **缺乏容错机制（覆盖前无本地快照）**：
   - 从文件导入或从 WebDAV 恢复时，一旦手误选错备份或云端被他人覆盖，原有本地配置瞬间被清空替换，无法撤销回滚。
5. **电视端（TV / 遥控器）输入成本极高**：
   - 遥控器输入长 URL、复杂 WebDAV 密码与 Token 体验极差，亟需近场互传或局域网扫码配网方案。

## 二、 界面结构重构：三段式场景化分区

将原先单一冗长的大表单，重构为层次分明的**三大独立功能板块**：

```
┌────────────────────────────────────────────────────────┐
│ 👤 当前用户档案与设备标识                                │
│   [ 档案名：客厅电视 ]   设备：Xiaomi TV Box 4K          │
├────────────────────────────────────────────────────────┤
│ 💾 本地文件备份与恢复                                    │
│   • 导出到文件（支持分类勾选 & AES-256 加密）            │
│   • 从文件恢复（智能识别档案归属、来源设备与加密状态）    │
├────────────────────────────────────────────────────────┤
│ ☁️ WebDAV 云端自动同步                                 │
│   • 状态指示：🟢 坚果云已连接 · 上次同步 10-15 12:00     │
│   • 快捷预设：[fnOS 飞牛] [群晖 Synology] [坚果云] [AList]│
│   • 服务器地址 / 鉴权信息 / 加密密码                      │
│   • [测试连接] 独立按钮                                 │
│   • 自动同步开关 (Switch)                               │
└────────────────────────────────────────────────────────┘
```

### 1. 档案与设备标识卡片
- 醒目显示当前档案名称（如“个人”、“客厅电视”、“卧室”、“父母”）与本机设备型号。
- 提供“重命名/切换档案”操作，让使用者在进行任何备份恢复前，清晰知晓自己当前所处的操作上下文。

### 2. 本地文件备份卡片
- **导出操作**：
  - 点击弹出导出选项对话框：包含备份内容分类勾选（见第三节）与加密密码输入；
  - 若密码留空，提示明文风险（琥珀色安全警示：“明文包含网盘授权 Token 与影视库密码，请勿发送给不可信人员”）；
  - 导出文件名格式：`fanzhou-[档案标识]-[日期][-enc].json`。
- **导入操作**：
  - 选取文件后先解析 Header 元数据，弹出信息确认框（展示档案标识、备份时间、设备来源、加密状态）；
  - 加密文件引导输入密码解密；导入执行前自动在本地保存当前快照（见第四节）。

### 3. WebDAV 云端同步卡片
- **顶部状态栏**：连接状态圆点（绿色正常/红色异常/灰色未配置）+ 上次成功同步时间；
- **服务商快捷预设（Preset）**：提供一键填充常用 NAS 或云盘的端口和路径模板；
- **独立「测试连接」按钮**：单点验证 URL、用户名、密码与备份目录的读写权限，避免盲目同步时遇到 401/404 报错；
- **WebDAV 文件名自动绑定档案**（见第二节方案）。

## 三、 多设备与多用户协同策略（隔离与防撞车）

### 1. WebDAV 云端文件名与档案标识自动绑定
- **现状**：固定为 `davDir/fanzhou-config.json`。
- **改进方案**：
  - 默认档案：`fanzhou-config.json`；
  - 自定义档案：`fanzhou-config-[profileName].json`（如 `fanzhou-config-客厅电视.json`、`fanzhou-config-张三.json`）。
- **收益**：全家人或多台设备共用同一个 WebDAV 目录时，各自同步到独立文件，互不干扰、互不覆盖。

### 2. 云端备份多版本浏览与一键恢复
- 恢复时不再盲目读取单个写死路径，而是通过 WebDAV `PROPFIND` 扫描当前目录下的 `fanzhou-config-*.json` 列表；
- 弹窗展示云端所有设备/档案的备份条目（文件名、档案名、修改时间、文件大小），用户可自由点选任意一份进行恢复（例如在电视端一键选择拉取“手机端”的配置）。

## 四、 备份内容细粒度控制（分类勾选与数据脱敏）

在导出文件或设置同步时，支持按模块分类勾选：

```
[✓] 1. 媒体库与云盘源
    包含阿里云盘、115网盘、夸克网盘、百度网盘、WebDAV 挂载、Jellyfin/Emby 源及授权凭证。
[✓] 2. 播放历史与断点记录
    包含所有视频的历史播放进度、已看完标记及云端最近播放。
[✓] 3. 外挂字幕与在线服务凭据
    包含射手网(伪) Token、SubDL API Key、OpenSubtitles 凭据。
[✓] 4. 播放器个性化偏好
    包含双内核偏好 (Exo/MPV)、缓存加载大小 (32M~512M)、倍速选项、快进快退步长等。
```

### 核心价值：
- **安全分享**：勾选 [1]，取消 [2]，即可将配置好的影视媒体库安全分享给亲友，绝不泄露个人观影隐私；
- **多端差异化体验**：换机或电视配网时勾选 [1][2]，取消 [4]，避免大屏电视的播放内核与大缓存设置被手机的小屏偏好覆盖。

## 五、 数据安全容灾与本地自动快照（防覆水难收）

1. **导入前自动安全快照 (Pre-restore Safety Snapshot)**：
   - 在执行“从文件导入”或“从 WebDAV 恢复”覆盖本地前，系统自动在私有目录 `files/backup_snapshots/` 生成当前配置的轻量快照；
   - 默认保留最近 3 ~ 5 次快照（带有清晰的时间戳和操作前标识）。
2. **一键撤销 / 快照回滚**：
   - 设置界面底部提供「恢复历史快照」入口；
   - 一旦用户误操作覆盖或导入错误文件，可在 10 秒内一键撤销，恢复到导入前的状态，极大提升容错率和安全感。

## 六、 Android TV 大屏端特色优化（遥控器减负）

针对客厅电视、投影仪等 Android TV 设备键盘输入困难的问题：

1. **局域网扫码互传 / 网页快捷配网**：
   - 电视端点击「扫码导入配置」，电视屏幕显示二维码及局域网内网网址（如 `http://192.168.1.100:8899`）；
   - 用户使用手机微信或浏览器扫码打开极简网页，点击“将手机配置发送至电视”或上传备份文件，电视端实时生效。
2. **同局域网近场设备发现**：
   - 手机端检测到同一 WiFi 下运行的泛舟电视端，提供“一键投送媒体库配置至 [客厅电视]”功能。

## 七、 实施落地规划建议（按优先级演进）

| 优先级 | 功能模块 | 预期成效 | 复杂度 |
| :--- | :--- | :--- | :--- |
| **P0（基础体验）** | • 界面三段式视觉重构（档案卡片、本地备份、WebDAV 同步）<br>• 增加 WebDAV「测试连接」独立按钮<br>• 明文导出时的醒目安全警示 | 界面整洁专业，解决连接配置黑盒问题 | 低 |
| **P1（多端防撞车）** | • WebDAV 云端文件名绑定档案名（`fanzhou-config-[档案].json`）<br>• 导入/恢复前自动保存本地安全快照（支持一键回滚） | 彻底消除多人共用冲突，提供坚固的容灾机制 | 中 |
| **P2（精细与易用）** | • 导出/同步支持分类选择（媒体源、播放历史、偏好）<br>• 电视端局域网扫码配网传配置 | 满足敏感凭据脱敏分享，大幅提升电视端录入体验 | 中高 |
