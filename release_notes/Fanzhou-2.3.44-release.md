# 泛舟 (Fanzhou) v2.3.44 更新日志

### 网盘文件数量显示升级（深度弹窗统计 + 记忆缓存与原生字段结合）

- **深度弹窗统计（长按文件夹 -> 文件夹信息）**：
  - **精准明细与总大小**：异步深度获取文件夹内部全量数据，展示总项目数、视频数、子文件夹数与其他文件数（例如「共 25 项（18 个视频，3 个子文件夹，4 个其他文件）」），并准确计算汇总所有子文件的总大小（带精确字节数）；
  - **平滑加载交互**：支持异步加载中进度动画，若本地已有缓存则秒级展示并后台刷新，获取完毕即时无缝回写至本地记忆缓存；
  - **当前文件夹信息入口**：顶部操作栏菜单新增「当前文件夹信息」，方便随时查看当前正在浏览的目录内容与容量统计。

- **记忆缓存与原生字段结合（列表、网格、海报卡片即时展示）**：
  - **架构引入 `FolderStatCache`**：采用高并发内存缓存配合持久化存储，用户在网盘浏览目录时自动记录已访问文件夹的项目数量与容量；
  - **网盘原生字段解析兼容**：深度适配网盘原生返回的文件夹子项数与容量字段（如 115 的 `c`/`fc`、夸克的 `file_num`、阿里云盘的 `file_count` 等），在初次加载目录时即可原生呈现；
  - **告别千篇一律的「文件夹」**：文件列表行、网格卡片以及海报卡片上的副标题全面升级，动态呈现「12 个视频 · 共 24 项」、「24 项」或「空文件夹」，网盘目录内容与集数分布一目了然。
