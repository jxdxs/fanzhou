# 泛舟 (Fanzhou) v2.3.42 更新日志

### 1. 设置页「备份同步」多后端二级菜单全新升级
- **入口精简重构**：
  - 将原「配置备份与同步」重命名为更直观精炼的「**备份同步**」；
  - 顶层聚焦保留核心的「当前用户档案标识」与「本地文件导入/导出」，界面结构大幅降噪。
- **新增多后端二级菜单选项卡**：
  - 云端服务区新增二级选项卡：`[WebDAV, SSH, 谷歌云盘]`，支持自由切换不同的远程同步方式。
- **WebDAV 交互分步流程重塑**：
  - **未登录状态**：呈现紧凑明晰的「WebDAV 登录」卡片，包含服务器地址、用户名、密码输入与一键登录验证，支持离线容错直接保存；
  - **已登录状态**：平滑切入「WebDAV 备份」管理界面，包含备份目录自定义、自动同步开关、立即同步、上传、恢复及快捷账号切换，彻底告别单页信息大堆叠。
- **扩展 SSH 与 Google 云盘凭据框架**：
  - 提供 SSH / SFTP 主机配置与 Google Drive 账号授权界面框架，为后续跨平台多后端无缝同步提供坚固支撑。

### 2. 优化「最近播放」起播与连播逻辑
- **最近播放直接继续播放**：
  - 用户从网盘「最近播放」卡片或首页「继续观看」行点击视频时，其意图明确为继续上次观影，播放器直接自动定位（Seek）至历史保存进度起播；
  - 彻底省去冗余的 10 秒倒计时继续播放悬浮窗，体验更加干脆利落。
- **目录浏览与选集/连播逻辑保持原样**：
  - 从普通目录/文件夹浏览点击视频、在播放器中点击「下一集」、或自动播放下一集时，保持原有逻辑；
  - 默认从 0 秒开始播放，若检测到该集存在 3 秒以上的历史断点，仍会弹出 10 秒倒计时悬浮窗让用户自主决定是否继续，兼顾从头观看与接续体验。
