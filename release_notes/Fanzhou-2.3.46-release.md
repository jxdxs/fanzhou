# 泛舟 (Fanzhou) v2.3.46 更新日志

### 1. 彻底解决悬浮窗（画中画）关闭后后台漏音问题
- **生命周期精准闭环与彻底销毁**：
  - 用户在画中画悬浮窗界面点击右上角的关闭按钮「X」或滑走关闭浮窗时，无论系统先回调 `onStop` 还是 `onPictureInPictureModeChanged`，均 100% 触发瞬时静音（`player.pause()` / `mpv pause`）与会话释放；
  - 结合 `isPipActive` 浮窗活跃标记与 `Lifecycle.State.CREATED` 状态判定，在退出浮窗分支中主动调用 `finish()` 彻底结束后台页面，杜绝任何系统版本或定制 ROM 下的后台幽灵音频。

### 2. 播放缓存加载全面升级为「双条件协同控制」（解决快进卡顿与突发加载停顿）
- **缓存空间（MB）与预加载时长（分钟）双重条件协同联动**：
  - **缓存加载空间**：支持 `64MB / 128MB / 256MB / 512MB`（默认 256MB），设置播放器最大内存使用上限，防止大码率视频导致 OOM；
  - **预加载缓冲时长**：支持 `1分钟 / 2分钟 / 3分钟 / 5分钟`（默认 2分钟），设定向前拉取数据的深度时间窗。
- **双内核流式缓冲调优（ExoPlayer 与 MPV）**：
  - **ExoPlayer 内核**：动态适配 `minBufferMs`（保持 75% 高水位平滑补水，避免连接空闲断开与陡然加载），重缓冲起播阈值（`bufferForPlaybackAfterRebufferMs`）由 5 秒优化至 2.5 秒，保留 60 秒后向缓存，快进或微调回跳秒级接播；
  - **MPV 内核**：深度启用 `demuxer-readahead-secs` 与 `cache-secs` 对应预加载时长（打破原先仅 10 秒预读的硬限制），开启 `demuxer-seekable-cache` 与 128MB 回退缓存，高频快进时直接在内存缓存区快速 Seek，极大改善卡顿。
