# 泛舟 (Fanzhou) v2.3.47 更新日志

### 1. 屏幕双击快退/快进体验优化
- **取消屏幕中心提示图标**：
  - 快速点击屏幕左侧/右侧两次触发快退与快进时，彻底取消屏幕正中心弹出的快退/快进图标与提示文字；
  - 触发跳转时画面纯净清爽，完全避免弹窗遮挡字幕与关键画面内容。

### 2. 预加载「双条件协同控制」逻辑重构（需同时满足两项条件）
- **真正实现「双条件完全满足」规则（以 512MB + 5分钟为例）**：
  - **彻底摒弃单一条件提前停载**：原先无论时间达到或大小达到任一条件就会停止预加载，导致小码率视频达不到设定缓存容量、或大码率视频达不到设定缓冲时长；
  - **持续预加载直到两者兼备**：播放器将保持持续预读，直到【缓存空间达到设定上限】（如 512MB）且【时间深度覆盖设定时长】（如 5分钟）两者【同时达成】（或到达文件末尾）才会停止预加载；
- **双内核深度重构**：
  - **ExoPlayer 内核**：引入专门的 `DualConditionLoadControl` 自定义控制层，精准判定 `sizeMet && timeMet`，结合设备安全堆上限持续平滑缓冲，彻底消除快进卡顿；
  - **MPV 内核**：扩展预读时间窗口，避免因时间达标而提早结束加载，确保持续向内存缓冲池喂满目标容量与时长深度。

### 3. 播放器底栏控制栏全透明化升级
- **除控制按钮外其他区域全透明**：
  - 彻底移除播放界面底栏原有的深色遮罩背景，将背景渐变与底栏色块均调整为完全透明；
  - 控制条唤出时底层画面内容毫无遮挡、清晰可见；
  - 全面兼顾 ExoPlayer 与 MPV 双播放内核，带来通透沉浸的观影体验。
