# 泛舟 (Fanzhou) v2.3.39 更新日志

### 1. 修复 AB 片段循环面板列表渲染崩溃（闪退修复）
- **根因修复**：彻底排查并修复 `ScrollView` 布局参数在列表渲染初期的空指针异常（NPE）。
- **告别闪退**：解决新增一个 AB 片段后直接闪退退出播放界面、以及再次进入视频点击「AB」按钮直接闪退退出的问题。
- **稳定性增强**：多段 AB 片段管理与列表渲染在 ExoPlayer 与 MPV 双内核上均已通过完备自动化用例验证。

### 2. AB 片段循环新增界面交互优化
- **时间微调长按连续快速步进**：新增界面的 A 点与 B 点步进按钮（`-10s`、`-1s`、`+1s`、`+10s`）现已全面支持长按手势（350ms 触发长按，每 90ms 连续自动步进），单手长按即可极速定位目标秒数，大幅提升区间调节体验。
- **新增界面逻辑调整为「先保存」**：新增面板底部操作按用户要求调整为「返回」与「保存」，保存后返回片段列表界面，用户可清晰查看已保存的各段片段，并在列表中按需点选任意片段进入循环播放，避免以往直接保存并强制关闭弹窗的突兀感。

### 3. 最近播放退出时不误清零原播放进度
- **保护历史播放进度**：针对已有播放记录的视频（如曾播放到 5 分钟），点击进入播放后，若在 10 秒悬浮倒计时期间或短时间内（1 分钟内）未点击「继续播放」即退出播放器，系统自动保留原历史播放进度（5 分钟），不再因视频刚起播于 0 秒而将进度覆盖归零。
- **双内核无缝适配**：点击「继续播放」或正常观看/快进超过历史进度后，正常接续保存新进度；ExoPlayer 与 MPV 双内核 100% 同步生效。

### 4. 修复 512MB 缓存设置导致退出播放界面的问题
- **开启大内存支持**：在 Manifest 中启用 `android:largeHeap="true"`，显著扩充应用可用内存上限。
- **双内核自适应熔断防护**：
  - **ExoPlayer 内核**：动态读取运行时虚拟机最大堆限制，将加载缓存严格限制在堆上限的 40% 以内，彻底避免 Java 堆 OutOfMemoryError 闪退。
  - **MPV 内核**：限制 demuxer 缓存最大 256MB，防止底层 C/C++ 内存开销过大触发 Android Linux 内核 LowMemoryKiller (LMK) 杀进程强退。

### 5. 播放控制栏交互去冗精简
- **去除右下角菜单重复防误触项**：由于屏幕右侧中位已常设防误触（锁屏）悬浮按钮，右下角齿轮菜单不再保留重复的「防误触」入口，精简菜单选项，使操作逻辑更直接。
