# 泛舟 (Fanzhou) v2.3.43 更新日志

### 播放进度记忆起播策略深度优化
- **全场景进入默认继续播放**：
  - 用户从任何界面点击进入视频，只要之前存在 3 秒以上的播放记录，全部**默认直接继续播放**：
    - 网盘/云盘「最近播放」记录点击；
    - 文件夹/目录内部点击任意视频；
    - 首页「继续观看」及各类视频卡片点击；
    - 媒体库网格与剧集详情页点击播放。
  - 播放器直接定位（Seek）至历史保存断点起播，彻底告别 10 秒倒计时继续弹窗的反复干扰，起播体验极速流畅。
  - （*注：若在详情页或长按操作中显式选择「从头播放」，仍严格按用户指令从 0 秒重新起播*）。

- **播放界面内部切集默认从头播放**：
  - 在播放控制界面中手动点击「下一个 / 下一集」；
  - 剧集播完自动连播下一集。
  - 以上切集场景默认从 **0 秒（片头）** 开始播放；若检测到即将播放的剧集在历史记录中存在进度断点，将保留 10 秒倒计时悬浮窗，让用户自主决定是否继续，兼顾从头观看新一集与多端历史断点的接播需求。
