# 泛舟 v2.3.51

- 修复连续多次快退卡顿（快进一直流畅，快退不行）：
  - **回看缓冲放大**：ExoPlayer 回看缓冲由固定 60 秒改为随预加载档位放大（3/5/8 分钟 → 保留 1.5/2/3 分钟已播放内容）。原先快退几下就越出 60 秒回看区，ExoPlayer 会清空全部前向预加载并重新联网请求，造成明显卡顿；现在连续快退直接命中内存缓冲。
  - **连点合并跳转**：连续点击快退/快进（底栏按钮、双击屏幕、遥控器/键盘）时，第一下立即跳转，后续点击在目标上累加，停手 160ms 后只做一次精确跳转，避免每次点击都重置解码器重新从关键帧解码。
  - **防断流保护**：回看缓冲与前向预加载共享内存预算；前向缓冲不足 30 秒时允许小幅越过软上限（不超过硬上限：软上限 ×1.25 且 ≤ 堆内存 45%），兼顾流畅与防 OOM。
  - **MPV 内核**：回看缓存（demuxer-max-back-bytes）由 16~64MB 提升到 32~128MB（原生内存，不占 Java 堆）。
- WebDAV 浏览体验与 115 等网盘完全一致：WebDAV 源改用网盘浏览页，支持视频缩略图与续播进度条、最近播放、收藏文件夹/视频、文件夹内搜索、列表/网格/海报多视图、升降序与文件夹优先、面包屑路径、文件夹/文件信息、下拉刷新与骨架屏加载；同目录字幕自动挂载，旧版 WebDAV 的续播进度自动迁移不丢失。SMB 仍使用原文件夹页。
