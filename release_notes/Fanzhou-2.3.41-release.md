# 泛舟 (Fanzhou) v2.3.41 更新日志

### 1. AB 循环片段长按操作弹窗层级遮挡 Bug 修复
- **彻底解决操作弹窗被底层片段框遮挡问题**：
  - 移除底层片段框多余的高层级 elevation 压制，杜绝 Android 硬件加速渲染管线将弹窗强制绘制在底层的现象；
  - 为长按弹出的操作对话框（「编辑」/「删除」）与卡片赋予高层级 elevation (`50dp` / `52dp`) 与 `translationZ`，确保弹窗 100% 浮于最前端；
  - 弹出操作对话框时自动将底层列表半透明淡化（alpha = 0.35），关闭时即时复原，视觉层级分明且交互完全聚焦。

### 2. 取消播放起播时右下角字幕搜索浮窗
- **去冗精简播放交互**：
  - 彻底移除打开视频时在右下角自动弹出的「💬 匹配在线中文字幕」悬浮气泡，避免干扰视线与遮挡控制区域；
  - 保留手动搜索字幕能力：当用户需要时，仍可随时通过控制栏字幕菜单中的「在线搜索字幕…」按需搜索与挂载字幕。
