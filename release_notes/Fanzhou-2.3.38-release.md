# 泛舟 (Fanzhou) v2.3.38 更新日志

### 1. 悬浮窗（画中画 PiP）与横屏播放双向对称无缝过渡
- **横屏 $\leftrightarrow$ 悬浮窗互逆对称**：彻底解决画中画悬浮窗返回横屏全屏时，首个动作画面拉伸裁切、非等比变形的问题，实现 A 到 B 到 C 与 C 到 B 到 A 路径完全一致。
- **首帧展开前预计算目标区域**：在视频视图与容器的 `OnLayoutChangeListener` 中捕获全屏重排版事件，在系统过渡动画首帧触发前，向 WindowManager 动态提交精确计算的全屏无黑边视频显示区域 `sourceRectHint`，杜绝系统因无目标位置而强制铺满 20:9 屏幕造成的视频上下边缘裁切。
- **ExoPlayer 与 MPV 双内核 100% 同步支持**。

### 2. 锁屏防误触增加二次确认解锁弹窗
- **双层防护**：点击锁屏悬浮按钮时，不再直接盲目解锁，而是弹出确认解锁对话框，提供更强一层的防护，避免携带或误触导致误解除。
- **紧凑无冗余空白设计**：采用精致圆角深色卡片设计，去除多余空白区域与内边距，提供「取消」与「确认解锁」双按钮；点击卡片外任意区域自动取消并重置锁图标淡出倒计时。
- 双内核统一生效。

### 3. 配置备份与同步安全加固（AES-256-GCM 强加密）
- **杜绝明文凭据泄漏**：包含各网盘 Access/Refresh Token、账号密码及 Jellyfin 凭证的备份文件支持密码加密导出。
- **工业级密码套件**：基于 `PBKDF2WithHmacSHA256`（65536次迭代 + 16字节强随机 Salt）派生密钥，结合 `AES-256-GCM` 进行带认证标签的强加密，他人获取备份文件无密码绝对无法破解。
- **智能兼容与校验**：自动识别明文与加密备份，加密文件自动弹出密码输入框解密，输入错误友好拦截并提示。
- **WebDAV 端到端密文同步**：支持独立云端加密密码，上传至服务器的数据全程以密文存储与同步。

### 4. 多用户档案隔离与使用者区分
- **用户档案 / 身份标识**：支持设置档案名（如“个人”、“客厅电视”、“张三”等），导出文件自动命名为 `fanzhou-[档案标识]-[日期].json`。
- **元数据来源提示**：备份文件内置档案元数据与源设备信息，导入时明确提示所导入档案名称、设备与备份时间，防止误将他人或他机配置覆盖。
- **WebDAV 独立目录与独立密码**：满足家庭多人、多设备使用隔离需求。

### 5. 设置界面增加播放缓存加载设置（可调节缓存大小）
- **缓存大小灵活调控**：在「设置 -> 播放」中新增「播放缓存加载大小」设置，支持 32MB ~ 512MB 动态滑块调节与快捷预设（32M/64M/128M/256M/512M）。
- **双内核深度适配**：
  - **ExoPlayer**：动态配置 `DefaultLoadControl` 的 `targetBufferBytes`、最小/最大缓冲时长与回退缓冲，增大缓存可抵御弱网抖动与云盘限速波动，实现平稳流畅播放；
  - **MPV**：根据所设缓存值动态调控 `demuxer-max-bytes` 与 `demuxer-max-back-bytes`。

### 6. 播放界面底栏新增「AB」片段循环
- **控制栏「AB」按钮**：ExoPlayer 与 MPV 双内核同步在底栏加入「AB」循环按钮，点击弹出精致紧凑、无多余空白的半透明管理面板。
- **自定义区间与微调**：支持「+ 新增片段」，一键填入当前播放时间为 A 点或 B 点，支持 ±1 秒 / ±5 秒精准微调步进；可自定义片段名称，支持针对单视频创建多段循环区间并持久化存储。
- **循环播放与状态高亮**：支持随时切换片段循环，激活后底栏「AB」按钮高亮为蓝色；播放到达 B 点或跳出区间时自动精确重播 A 点；面板内支持一键停止循环；切集自动复位。
- **防误删二次确认**：每个片段右侧配备删除按钮，点击弹出紧凑型二次确认对话框（「确定删除该 AB 片段吗？」），严格遵循无空白设计规范，提供双层防护防止误操作。
