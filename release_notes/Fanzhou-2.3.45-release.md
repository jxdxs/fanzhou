# 泛舟 (Fanzhou) v2.3.45 更新日志

### 修复画中画悬浮窗点击右上角「X」关闭后后台仍有声音播放的问题

- **双内核生命周期严密闭环（ExoPlayer 与 MPV 双播放内核）**：
  - **精准拦截浮窗关闭事件**：当用户在画中画悬浮窗界面点击右上角的关闭按钮「X」或滑走关闭浮窗时，精准捕捉 Activity 销毁（`isFinishing || isDestroyed`）信号；
  - **消除全屏误触复原逻辑**：彻底修复原先在关闭浮窗退回全屏模式分支中，未检测 Activity 销毁状态而误走全屏 UI 复位流程，导致播放器未被暂停并持续解码播放的严重缺陷。

- **瞬时停止与资源彻底释放（`stopPlaybackAndCleanUp`）**：
  - **毫秒级停音与进度记录**：用户点击「X」瞬间即刻执行播放器 `pause()` 并精准记录保存当前断点进度，杜绝窗口关闭后声音在后台长鸣的幽灵播放现象；
  - **媒体会话即时释放**：同步将 `MediaSession` 置为非活跃并彻底 release，清除系统通知栏与锁屏界面的媒体控制残留，避免耳机按键误触发重新拉起播放；
  - **多层级双重拦截防护**：在 `onPictureInPictureModeChanged` 与 `onStop` 两处生命周期关键节点同时部署防护拦截，全面兼容 Android 各大原生版本以及厂商定制 ROM 的浮窗关闭时序。
