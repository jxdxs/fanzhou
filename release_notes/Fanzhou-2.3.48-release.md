# 泛舟 (Fanzhou) v2.3.48 版本更新说明

## 本次更新亮点

### 1. 彻底修复播放界面多次闪退及异常退出问题
- **堆内存溢出（OOM）根治**：
  - 去除原先强制设定 512MB 等超大空间缓存导致的 Java 堆内存爆仓（`OutOfMemoryError`）；
  - 引入严格的堆内存安全防护红线（严格限制缓存内存占用不超过 JVM 可用堆内存的 35% 且上限 256MB），从底层根除大文件与高清流媒体预加载导致的闪退。
- **画中画/悬浮窗还原恢复健壮性优化**：
  - 修复从画中画窗口点击还原全屏时，因生命周期状态瞬时延迟误判为关闭而导致播放器界面意外退出退回上一级的隐患。
- **媒体源切换安全边界保护**：
  - 为画质切换与源重载添加完备的索引边界校验与异常安全捕获，杜绝并发越界崩溃。

### 2. 预加载配置深度精简优化（纯时间驱动）
- 仅保留预加载时间档位，去除容易导致内存溢出的空间大小（MB）选项；
- 预加载缓冲时长全面更新为 **3 分钟 / 5 分钟 / 8 分钟** 三档，设置更直观简洁；
- 播放器持续向前拉取设定时长的流媒体数据，保障拖动快进、跳集与切画质时的秒开流畅。

### 3. 非原画质（转码画质）预加载与缓冲显示全面强化
- **阿里云盘转码流升级**：优先采用 `quick_video` 极速转码通道，获取完整的切片清单列表，支持 3/5/8 分钟深度预加载，彻底解决原画可预加载而转码画质仅能预载十几秒的切片限制。
- **MPV 缓冲进度条修复**：修复 MPV 进度条将相对预读秒数误算为绝对时间差导致缓冲进度条归零卡死的缺陷，准确呈现灰度缓冲进度。
- **ExoPlayer HLS 流水线调优**：禁用 HLS chunkless preparation 延迟加载机制，强制主动流水线预读切片，并确保 Jellyfin 等各转码通道的 MIME 类型准确识别。
