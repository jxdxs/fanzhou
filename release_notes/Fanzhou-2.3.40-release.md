# 泛舟 (Fanzhou) v2.3.40 更新日志

### 1. AB 循环列表项交互升级与防误触删除强化
- **取消尾部常设删除按钮**：移除每个 AB 循环片段行尾部的「🗑」删除按钮，界面布局更舒展，彻底消除在滑动列表或点按启动循环时的误删隐患。
- **长按片段呼出操作菜单**：长按任意已保存的片段，即刻弹出精致紧凑的操作菜单，包含「编辑」与「删除」选项，点击外部或「取消」即可关闭。
- **支持片段二次编辑**：点击「编辑」进入编辑模式，自动回填当前片段的名称与 A/B 点时间；调整完成后点击保存，若该片段当前正处于循环播放中，系统将实时平滑更新循环区间。
- **二次确认删除防护**：点击「删除」后弹出确认对话框，清晰展示该片段的名称、起止时间与总时长，用户二次确认后方可删除，提供坚实的防误触保障。
